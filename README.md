## 🚀 ¿Qué es NutriTrack Go?

**NutriTrack Go** es una aplicación ligera y completamente local que te ayuda a llevar un control de:

- 🥣 **Calorías consumidas**
- 💧 **Agua ingerida**
- 🍽️ **Recetas saludables**
- 📊 **Recomendaciones personalizadas** basadas en tu sexo, edad, altura y estilo de vida

> 🧠 **Privacidad total**: No necesitas registrarte. Todos tus datos se guardan localmente en tu dispositivo.

---

## 🌟 Características principales

- ✅ Seguimiento diario de alimentos y agua
- 🔍 Recomendaciones de calorías personalizadas
- 🍳 Recetario integrado (versión beta)
- 📅 Registro simple, sin necesidad de cuenta
- ⚡ Sin conexión: funciona completamente offline

## 🛠️ Instalación

1. Clona este repositorio:
   ```bash
   git clone https://github.com/Martinuski400/NutriTrackGo.git
Instala las dependencias:
  ```bash
  npm install
  ```
Ejecuta la app:
  ```bash
npm start
  ```
⚠️ Requiere Node.js y un entorno de desarrollo compatible con React Native / Electron / (dependiendo del stack que uses)
