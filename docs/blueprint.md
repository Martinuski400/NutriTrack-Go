# **App Name**: NutriTrack Go

## Core Features:

- Calorie Input: Allow users to input their daily calorie consumption. Should include fields for meal type, food items, and calorie count.
- Water Tracker: Visually represent daily water intake with a progress bar and set daily hydration goals.
- Water Chart: Display historical water intake data in a visually appealing chart.

## Style Guidelines:

- Primary color: Teal (#008080) for a fresh and healthy feel.
- Secondary color: Light Gray (#D3D3D3) for neutral backgrounds.
- Accent: Orange (#FFA500) for notifications and highlights.
- Implement a bottom navigation bar for easy access to the calorie tracker, water tracker, and settings.
- Use simple, outlined icons for the bottom navigation bar and other UI elements.
- Subtle animations for progress updates on the water intake tracker.
